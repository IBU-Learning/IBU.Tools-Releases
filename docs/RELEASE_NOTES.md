# IBU.Tools Release Notes

## v0.9.0 Preview — Unreleased / validation in progress

The installer is not yet publicly available. Manual acceptance testing remains in progress.

Planned Preview characteristics:

- No-cost, immediate local access through **30 November 2026 (UTC)**.
- Support for Revit 2024, 2025, 2026.5 or later, and 2027.
- Schedule Export, Schedule Import, Print Center, Sheet Manager, Parameter Manager, and Health Check.
- Fully offline product operation with no login, licence key, device registration, telemetry, analytics, or automatic network requests.
- User-initiated Help and Documentation links to the public guide and an Update link to this repository's Releases page.

Use copied models during evaluation and verify all results. Final installer checksum, manual validation status, and release date will be added only after validation is complete.
